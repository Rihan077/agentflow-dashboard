
# AgentFlow Dashboard

> AI Agent Hosting Platform — Built by Rihan & Disha

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://agentflow-dashboard-4uiuz93gbhkuyvqykprjru.streamlit.app)

## Features
- 🔐 JWT Authentication — login/logout
- 🤖 Register custom AI agents with real UUIDs
- 💬 Chat with agents — session memory included
- 📊 Real-time cost and token tracking
- 🔢 Rate limit display — 100 calls/day
- 📋 My Agents panel — switch and delete agents

## Tech Stack
- Frontend: Streamlit
- Backend: AWS Lambda (Python 3.11) + API Gateway
- AI: LangChain + OpenAI GPT
- Database: AWS DynamoDB
- Auth: JWT tokens
